# Ation Password

Foram realizadas adequações com base no projeto inicial, para a publicação da ferramenta.

## Funcionalidades
- Aplicação desktop para gerar senhas de forma aleatória;
- A aplicação possuifuncionalidade de aumento de complexidade adicionado:
  - Letras maiúsculas;
  - Números;
  - Símbolos;
  - Comprimento da senha.
